NFT Dealers is a NFT marketplace with pre-set supply, and resell option with Progressive fee 1, 3 or 5%. NFTs can be sold by users on any price, but the fee will grow with the resell price. Can be used for in-game events, ticketing system, no limited to any specific purpose.

## Roles

**Owner:**
- deploy the smart contract and set parameters (collateral, collection name, image, symbol, etc.)
- whitelist or remove from whitelist wallets
- `reveal` the protocol
- withdraw fees

**Whitelisted user/wallet:**
- mint NFT
- buy, update price, cancel listing, list NFT
- collect USDC after selling

**Non whitelisted user/wallet:**
- cannot mint
- buy, update price, cancel listing, list NFT
- collect USDC after selling
